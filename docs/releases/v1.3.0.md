# 弈境 v1.3.0

本版合并完成原升级规划中的可靠性、对弈工具和复盘学习三个阶段。

这次升级完善了从开始对局、中断恢复，到终局、棋谱保存和复盘的完整流程，并修复影响对弈可信度的问题。

## 修复与可靠性

- 大厅一次点击直接继续上次棋局，AI 回合自动接续。
- 有效操作后自动保存，摆谱作为独立草稿保留；旧存档保留备份并迁移。
- 棋盘、悔棋、分支和导出使用统一历史，重开后的棋谱不再混入上一局。
- 修复象棋与国际象棋 AI 评分视角，加入时间预算、递归取消和过期结果校验。
- 补齐围棋停着记录与规则状态恢复；修正终局、困毙、国际象棋特殊规则及 SAN 记谱。

## 新的对弈与学习工具

- 集中对局设置、横屏布局、四个主要操作、19 路落点预览与可见推荐走法。
- 完整摆谱开局设置、局面校验、执子方选择及棋盘翻转。
- 棋谱文件导入预览、系统保存与分享，支持 PGN、SGF 和 FEN。
- 多棋局库、缩略图、名称／棋类／时间／状态筛选，支持删除撤销。
- 逐步复盘、分支推演、注释及三道精选入门练习。
- 主题、高对比、坐标、音效、震动、动效与棋盘无障碍操作。

## 安装与更新

- 正式包启用代码与资源压缩，显著减少下载体积。
- 系统后台下载可在离开页面后继续，保留任务和进度入口。
- 安装前校验版本、包名、签名、长度及发布摘要，补齐授权和失败重试流程。
- Android 11 及以上；沿用已发布版本的签名，可覆盖安装并保留棋局。

## 验证

- 51 项单元回归、25 项 Mi 9 SE／Android 15 真机测试通过。
- 独立 PGN／SGF 阅读器校验 7 份棋谱；Release lint 与 GitHub CI 通过。
- 已验证旧包升级迁移、横竖屏／大字体、系统文件保存与导入、分享面板及安装授权拒绝后重试。

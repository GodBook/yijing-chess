# 弈境 (YiJing) - 多合一棋类对弈与摆谱移动应用

<p align="center">
  <b>方寸乾坤 · 棋乐无穷</b><br>
  一款基于 Jetpack Compose 开发的高品质、无广告棋类对弈与排局研讨 Android 应用。<br>
  内置<b>中国象棋</b>、<b>围棋</b>、<b>国际象棋</b>，支持人机对战（多级启发式 AI）、双人同屏对弈、自由摆谱及 SGF / PGN / FEN 棋谱导入导出。
</p>

---

## 🌟 核心特性 (v1.1.0 升级版)

- **下边栏一键切换棋类**：
  - 全新底部导航栏（Bottom Navigation Bar），用户可在【大厅】、【中国象棋】、【围棋】、【国际象棋】之间随时便捷切换。
- **棋局中途保存与恢复**：
  - 对局下到一半退出（系统返回键、顶部返回箭头或切换下边栏）时，自动弹出保存确认提示。
  - 支持【保存并退出/切换】、【不保存】或【取消】；保存后可在对应棋类或大厅一键【恢复棋局】继续对弈。
- **多级 AI 难度引擎（初级 / 中级 / 大师）**：
  - **中国象棋 AI**：引入 Negamax + Alpha-Beta 剪枝、兵力位置表 (Piece-Square Tables: 车占通头、马据中心、炮挂中沉底、兵卒过河推进)、静态吃子延伸搜索 (Quiescence Search)，彻底解决地平线效应与漏看大子问题。
  - **围棋 AI**：升级双叫吃 (Double Atari) 制造与防范、做眼识别与防守、金角银边开拆、以及大师难度下的 2-Ply 局部深度反击推演，兼具大局观与战术敏锐度。
  - **国际象棋 AI**：完整 PST 位置估值（车控开放线与第7排、马居中心、王车易位王堡安全）、大师级静态捕获延伸搜索，杜绝送子盲区。
- **流畅性与稳定性深度优化**：
  - 彻底修复围棋落子时信息栏换行导致棋盘跳跃抖动的问题。
  - 彻底修复中国象棋落子时 AI 搜索中间状态直接修改 UI 棋盘引起的短暂形变与闪烁问题。
  - Canvas 绘制层 Paint 对象池化与复用，杜绝频繁 GC 内存抖动。
  - 协程安全协同取消机制，悔棋、重新开始或退出时立即中断后台搜索。
- **三大棋类一站式内置**：
  - **中国象棋**：9列10行传统木纹盘面与楚河汉界，完整判定别马腿、相塞眼、炮翻山隔子吃子、九宫限制与飞将（将帅照面实时阻断），生成标准中文记谱。
  - **围棋**：支持 19×19路（标准大盘）、13×13路（中盘研讨）、9×9路（死活启蒙），动态计算气数、自动提子、双方提子统计、禁自杀与单子打劫（Ko）规则，支持停着（Pass）。
  - **国际象棋**：8×8 经典木质棋格，标准王车易位（O-O / O-O-O）、吃过路兵（En Passant）、兵升变选择弹窗（后/车/象/马），代数记谱法追踪。
- **自由排局摆谱 (Board Editor)**：
  - 专属摆谱模式：底部提供双方可用棋子托盘，支持自由放置棋子、橡皮擦单格清除、清空棋盘与初始重置。
  - 排好残局或死活题后，可一键切换开启人机对战从当前局面继续推演。
- **主流棋谱导入导出**：
  - 围棋与象棋支持导出标准 SGF 格式。
  - 国际象棋与象棋支持导出标准 PGN 与 FEN 格式。
- **在线自动更新**：
  - 内置 GitHub Releases 在线更新检查与下载安装功能，支持一键升级至最新版本。

## 📱 系统兼容性

- **最低支持版本**：Android 11 (API Level 30)
- **目标版本**：Android 15 / 16 (API Level 35/36)
- **架构**：全纯净架构，纯 Kotlin + Compose，自适应深色古风沉浸主题。

## 🛠️ 构建与安装

### 本地编译
```bash
# 编译并生成 Debug APK
./gradlew assembleDebug

# 运行规则单元测试
./gradlew verifyChessRules
```

编译生成文件位于：`app/build/outputs/apk/debug/app-debug.apk`

### 安装到设备
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
